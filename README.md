# 🎃 Halloween Git Rescue: Server Room Horror

## Presentació

És la nit de la vespra de Tots Sants (31 d'octubre), a les 23:45 h. Estàs sol/a a les oficines i, de sobte, els llums tremolen i una alarma vermella il·lumina la terminal: un antic desenvolupament maleït, `fantasmes_in_production.js`, s'ha despertat a l'historial del projecte i un programador desaparegut injecta codi maliciós des d'una dimensió temporal paral·lela.

La missió és actuar com a enginyer/a de *Forensic Software* amb Git:

- Reconstruir el repositori local des de zero.
- Aïllar diferents línies temporals (branques) i fusionar-les, resolent el conflicte resultant.
- Viatjar en el temps per eliminar el commit infectat i purificar l'historial.
- Publicar el repositori net a GitHub per a l'auditoria final.

L'aplicació del cas d'estudi és un petit programa en Java ([`main.java`](main.java)) que simula el sistema de seguretat d'una sala de servidors: control d'accés, alarma i nivell de seguretat.
